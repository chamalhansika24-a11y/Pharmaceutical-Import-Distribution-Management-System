# Pharmaceutical Import & Distribution Management System

A web-based database management application designed to streamline the import, inventory management, and distribution processes of pharmaceutical products to clients (hospitals and pharmacies) in Sri Lanka.

---

## 📌 Project Overview
* **Course:** CSC 209 2.0 - Database Management Systems
* **Institution:** Department of Computer Science, University of Sri Jayewardenepura
* **Group:** Group No. 13

---

## ✨ Key Features
* **Client Management:** Registration and authentication for Hospitals and Pharmacies with dynamic client type specialization.
* **Medicine & Inventory Control:** Real-time stock tracking, unit price management, and batch expiry alerts.
* **Sales Order Processing:** Automated stock update upon order approval/cancellation and real-time status tracking.
* **Business Analytics & Reporting:** Real-time generation of monthly revenue reports, top-selling medicines, top clients, and 6-month expiry risk alerts.

---

## 🛠️ Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP (MySQLi)
* **Database:** MySQL / MariaDB (phpMyAdmin)
